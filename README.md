# Vantage Landing Page — Option 2

This repository contains the Option 2 variant of the Vantage landing page.

## Stack

- React
- TypeScript
- Vite
- Lucide React

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — run development server
- `npm run build` — create production build
- `npm run preview` — preview production build
