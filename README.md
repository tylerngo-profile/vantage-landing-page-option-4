# Enterprise Clarity

A React + TypeScript + Vite landing page project.

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` – start local dev server
- `npm run build` – production build
- `npm run preview` – preview production build
- `npm run lint` – run ESLint
- `npm run test` – run Vitest tests

## Tech stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
